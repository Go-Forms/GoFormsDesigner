# Сборка для браузера (WebAssembly)

Кроме Go ничего не нужно. **`GoForms: Build for WebAssembly`** делает три
вещи, все локально:

1. `GOOS=js GOARCH=wasm go build -ldflags="-s -w" -o build/wasm/<имя>.wasm .`
2. копирует `wasm_exec.js` — JavaScript-часть wasm-рантайма Go — из
   установки Go (`$(go env GOROOT)/lib/wasm/`, до Go 1.24 — `misc/wasm/`)
   в `build/wasm/`
3. копирует страницу-загрузчик из папки `wasm/` проекта (или, если её нет,
   из самого расширения) в `build/wasm/`, подставляя имя приложения и имя
   `.wasm`-файла

## Посмотреть

Браузер отказывается запускать `.wasm` со страницы `file://`, поэтому
двойной клик по `index.html` покажет пустой загрузчик.
**`GoForms: Serve WebAssembly Build in Browser`** поднимает маленький
статический сервер для `build/wasm/` — встроенный в Node, слушает только эту
машину, сеть не нужна — и открывает его.

Подойдёт любой статический сервер: например, `python3 -m http.server` в
`build/wasm`. Единственное требование — тип `application/wasm`; без него
встроенная страница загрузится медленнее, но загрузится.

## Публикация

Выложите `build/wasm/` как есть на любой статический хостинг. Серверной
части нет.

## Чем браузер отличается

- Главная форма — это страница. Форма, спроектированная больше вкладки,
  прокручивается (`Form.AutoScroll` там включён по умолчанию).
- Остальные формы открываются перемещаемыми окнами внутри страницы;
  `ShowDialog` блокирует страницу под ними и возвращает `DialogResult`
  при закрытии.
- Файловым диалогам нечего показывать — файловой системы нет. Держите данные
  в памяти или в `fyne.CurrentApp().Preferences()`, браузер хранит их
  локально.
- Первая загрузка скачивает всё приложение (несколько МБ в сжатом виде);
  повторная берётся из кэша.

## Если не собирается

- *`cannot find module` / `dial tcp`* — Go попытался скачать модуль. Один раз
  при наличии сети выполните `go mod download`.
- *`wasm_exec.js was not found`* — в установке Go нет папки `lib/wasm`
  (или `misc/wasm`); пакет дистрибутива мог её вырезать. Поставьте Go
  с <https://go.dev/dl/>.
- *Пустая страница с «This browser has no WebGL support»* — Fyne рисует
  через WebGL; включите аппаратное ускорение в браузере.
